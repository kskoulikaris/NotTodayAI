# 🚫 NotToday.ai

Helping people avoid self-improvement since 2026.

NotToday.ai is a humorous web app that allows users to select a New Year's resolution category and receive increasingly persuasive excuses for not following through.

## Features

- 11 Resolution Categories
- 80+ Resolutions
- Demotivation Meter
- Random Achievements
- Humorous Excuses
